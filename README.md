# PSYˣAXIS

Статический двуязычный сайт психологического, образовательного и исследовательского проекта PSYˣAXIS. Визуальная система: тёмная тема, золотые акценты, Playfair Display и Inter.

## Технологии

- семантический HTML5;
- общий `styles.css` без CSS-фреймворка;
- небольшой `site.js` для skip-link и доступного мобильного меню;
- формы FormSubmit (существующая интеграция);
- Python 3 standard library для локальных и CI-проверок.

## Структура

```text
index.html                 русская главная
ua/                        украинская версия с зеркальной структурой
spaces/                    индивидуальная работа, практики и школа
articles/                  русские статьи и рабочий документ
assets/                    графические ресурсы
styles.css                 общая визуальная система
site.js                    доступность и мобильная навигация
thanks.html                подтверждение отправки формы
docs/                      технические отчёты
scripts/check_site.py      проверки сайта
.github/workflows/         CI без публикации
```

Корневой `psychology-meditation.html` сохранён как совместимый переход на актуальный URL статьи. Исходные `.docx` и неиспользуемые изображения сохранены, но должны исключаться из production-публикации на уровне хостинга.

## Локальный запуск

Абсолютные пути требуют HTTP-сервера; открытие через `file://` не поддерживается.

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000/` и `http://localhost:8000/ua/`.

## Проверка

```bash
python scripts/check_site.py
```

Скрипт проверяет базовую структуру HTML, языки, метаданные, единственную `h1`, локальные ссылки, якоря, ресурсы, cache key CSS и структуру CSS. Он не заменяет браузерное тестирование, W3C Validator, Lighthouse и юридическую проверку форм.

Рекомендуемые ручные ширины: 320, 360, 390, 768, 1024 и 1440 px. Дополнительно проверьте клавиатуру, Escape в мобильном меню, reduced motion и обе локализации.

## Принципы изменений

- сохранять русскую и украинскую страницы синхронно;
- не менять тексты метода и позиционирование без решения автора;
- общие стили размещать в `styles.css`;
- единообразно обновлять cache key CSS и JS;
- не менять FormSubmit, адрес, поля или юридические тексты без согласования;
- не добавлять сборку или frontend-фреймворк без необходимости.

## Известные ограничения

- часть исторических страниц содержит inline-стили; перенос требует визуального regression-теста;
- изображения не имеют полного набора WebP/AVIF и `srcset`;
- реальные отправки форм автоматически не выполняются;
- юридическая корректность обработки данных не подтверждена;
- `.docx` и неиспользуемые медиа пока находятся рядом с публичными файлами.

## Публикация

Публикация выполняется только после review и слияния одобренного Pull Request в `main` согласно настройкам хостинга. Workflow автоматического деплоя отсутствует. Перед публикацией необходимо проверить production URL, формы тестовыми данными с разрешения владельца и исключение рабочих материалов.

Подробнее: [`docs/forms-and-privacy-review.md`](docs/forms-and-privacy-review.md).
