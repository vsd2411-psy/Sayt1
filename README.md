
# Сайт психолога Виталия Овсянникова

Современный премиальный веб-сайт для психолога, автора и преподавателя Виталия Овсянникова.

## 🎨 Дизайн и Стиль

- **Концепция**: Премиальный минимализм
- **Тема**: Глубинная психология и трансформация
- **Палитра**: Тёмный фон, золотые и графитовые акценты
- **Шрифты**: 
  - Заголовки: Playfair Display (элегантность)
  - Текст: Inter (читаемость)

## 📑 Разделы Сайта

1. **Главная (Hero)** - Впечатляющее вводное сообщение с CTA-кнопками
2. **Обо мне** - Информация о психологе и его опыте
3. **Метод** - Описание уникального подхода в 4 этапах
4. **Услуги** - 4 основные услуги с описанием и ценообразованием
5. **Курсы** - 3 авторских курса разного уровня
6. **Блог** - 6 последних статей о психологии и развитии
7. **Контакты** - Форма обратной связи и контактная информация

## 💻 Технологии

- **HTML5** - Семантическая структура
- **CSS3** - Адаптивные стили, анимации, гриды
- **JavaScript** - Интерактивность, валидация, анимации

## ⚡ Возможности

### Навигация
- Фиксированная навигационная панель с плавным скроллингом
- Мобильное меню (бургер-меню)
- Активная подсветка текущего раздела

### Интерактивность
- Плавная прокрутка между секциями
- Анимация карточек при появлении в представлении
- Счётчики статистики с анимацией
- Валидация формы обратной связи
- Уведомления об отправке формы

### Адаптивность
- Мобильная версия (480px и выше)
- Планшетная версия (768px и выше)
- Десктопная версия (1200px и выше)
- Гибкие гриды и макеты

## 📱 Адаптивность

```
- Мобильный телефон: 320px - 767px
- Планшет: 768px - 1023px
- Десктоп: 1024px и выше
```

## 🚀 Быстродействие

- Минималистичный CSS без лишних стилей
- Оптимизированный JavaScript с debounce
- Lazy loading для изображений
- Использование passive event listeners
- Анимации на GPU (transform, opacity)

## 🎯 CTA-Кнопки (Call-to-Action)

- **Первичные (Золотые)**: Основные действия (консультация, запись)
- **Вторичные (Обведённые)**: Альтернативные действия (подробнее)
- **Очертания (Outline)**: На карточках услуг
- **Полной ширины**: На мобильных устройствах и в формах

## 🛠️ Установка и Запуск

1. Клонируйте репозиторий
2. Откройте `index.html` в браузере
3. Или используйте локальный сервер:
   ```bash
   python -m http.server 8000
   # или
   npx http-server
   ```
